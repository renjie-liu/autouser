# Code of Conduct

## Our commitment

We want AutoUser to be a welcoming and respectful project for everyone who uses
or contributes to it, regardless of background or experience level.

## Expected behavior

- Be respectful of differing viewpoints and experiences.
- Give and gracefully accept constructive feedback.
- Focus on what is best for the project and its community.
- Show empathy toward other community members.

## Unacceptable behavior

Conduct that a reasonable person would consider inappropriate in a professional
setting — including personal attacks, demeaning or discriminatory remarks, or
sustained disruption of discussions — is not acceptable.

## Scope

This applies in all project spaces (issues, pull requests, discussions, and code
review) and when representing the project in public spaces.

## Reporting and enforcement

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its standard for expected conduct and enforcement guidelines. To
report a concern, open a private report via GitHub's **Security → Report a
vulnerability** channel on this repository, or contact a maintainer privately
through their GitHub profile. Reports will be reviewed and handled promptly and
fairly.
